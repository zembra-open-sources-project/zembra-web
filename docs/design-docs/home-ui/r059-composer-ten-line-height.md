# r059-composer-ten-line-height 设计文档

日期：2026-08-31

## 方案

复用 `LiveMarkdownEditor` 既有的 `overflow-y: auto` 自动扩展与内部滚动能力，仅调整 `src/styles/content/markdown.css` 中共享编辑区的高度边界。最小高度使用两倍现有 `1.5rem` 行高加既有上下内边距计算，最大高度使用十倍行高加相同内边距计算；因此创建笔记和卡片编辑共用同一行为，内容达到十行后继续在输入区内部滚动。

不新增组件、状态、依赖或测试对静态样式细节的断言。

## 验证

运行两种 Vite 生产构建，确认 CSS 改动可被正常编译，并检查差异只包含输入区高度边界和本需求文档。
